# TaskFlow User Stories

## User Registration
As a new user, I want to create an account so that I can manage my own projects and tasks.

# Acceptance Criteria
 User can register with name, email, and password.
 Email must be unique.
 Password is stored securely.
 User is redirected to the login page after successful registration.

## User Login
As a registered user, I want to log in so that I can access my dashboard securely.

# Acceptance Criteria
  User can log in with valid credentials.
  Invalid credentials display an error message.
  Only authenticated users can access protected pages.


## View Dashboard
As a logged-in user, I want to view my dashboard so that I can see all my tasks in one place.

# Acceptance Criteria
  Dashboard displays all tasks.
  Task statistics are shown.
  Empty state is displayed when there are no tasks.

## Create a Project
  As a logged-in user, I want to create projects so that I can organize related tasks.

# Acceptance Criteria
 User can create a new project.
 Project name is required.
 Newly created project appears in the project list.

## Create a Task
As a logged-in user, I want to create a task so that I can track my work.

# Acceptance Criteria
 Task title is required.
 User can select a project.
 User can choose status and due date.
 Newly created task appears in the task list.

## Edit a Task
As a logged-in user, I want to edit an existing task so that I can keep it up to date.

# Acceptance Criteria
 Existing task information is displayed.
 User can update task details.
 Changes are saved successfully.

## Delete a Task
As a logged-in user, I want to delete a task so that I can remove tasks I no longer need.

# Acceptance Criteria
 User can delete a task.
 Deleted task is removed from the task list.
 Dashboard updates automatically.

## Search and Filter Tasks
 As a logged-in user, I want to search and filter tasks so that I can quickly find specific tasks.

# Acceptance Criteria
 User can search tasks by title.
 User can filter tasks by status.
 Results update correctly.

## View Task Details
As a logged-in user, I want to open a task so that I can view all its information.

# Acceptance Criteria
 Task title, status, due date, and project are displayed.
 User can navigate back to the task board.


## Update Task Status
As a logged-in user, I want to change a task's status so that I can track its progress.

# Acceptance Criteria
 User can change the task status.
 Updated status is saved.
 Dashboard statistics are refreshed.


## Update Profile
As a logged-in user, I want to update my profile so that my account information stays current.

# Acceptance Criteria
 User can edit profile information.
 Changes are saved successfully.
 Updated information is displayed after refresh.
